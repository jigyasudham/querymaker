# QuerryHub: Professional SQL Architect

QuerryHub is a high-end, web-based SQL query building and database management suite designed for modern data architects. Featuring a sleek **Glassmorphism** interface, it provides an intuitive yet powerful environment for exploring schemas, constructing complex queries, and managing data infrastructure.

## ✨ Key Features

### 🔹 Advanced Query Builder
*   **Visual Construction:** Build complex SQL queries (JOINs, WHERE, GROUP BY, ORDER BY) using an intuitive drag-and-drop-ready interface.
*   **Smart Suggestions:** Context-aware column and join suggestions based on your schema and query history.
*   **Specialized Builders:** Dedicated modules for `CASE` statements and `String Concatenation` (`||`).
*   **Live SQL Preview:** Real-time generation of formatted, production-ready SQL as you build.

### 🔹 Infrastructure Management (Admin Center)
*   **User Ecosystem:** Comprehensive user onboarding and directory management with granular permission levels (Beginner, Intermediate, Advanced).
*   **Data Portals:** Register and configure multiple infrastructure endpoints with dedicated automation support.
*   **Schema Lifecycle:** Manage master metadata and automate schema fetching runs with detailed execution logs.

### 🔹 Developer Tools
*   **Schema Explorer:** High-performance, searchable tree-view of all authorized schemas, tables, and columns.
*   **Interactive Editor:** A premium SQL editor for writing and executing custom logic with syntax highlighting.
*   **Query Templates:** Save frequently used queries as templates for instant restoration and sharing.
*   **Enhanced History:** Track execution times and row counts for previous queries with bulk export capabilities.

## 🎨 Design Philosophy: Glassmorphism

QuerryHub utilizes a modern **Glassmorphism** aesthetic, emphasizing visual depth and clarity:
*   **Translucent Surfaces:** UI elements are rendered as "frosted glass" panels with `backdrop-blur` for a premium feel.
*   **Dynamic Backgrounds:** An animated mesh gradient provides a subtle, living backdrop that highlights the glass effects.
*   **Adaptive Themes:** Seamless support for both **Obsidian Dark** and **Soft Light** modes.
*   **Refined Typography:** Optimized for readability using *Inter* for UI and *JetBrains Mono* for code.

## 🚀 Technical Stack

*   **Frontend:** React 18 with Vite for lightning-fast HMR and performance.
*   **Styling:** Tailwind CSS 3 with custom glassmorphic utility extensions.
*   **Animations:** Framer Motion for smooth component transitions and physics-based interactions.
*   **Backend Integration:** Seamless communication with Python-based APIs for database connectivity and automation.

## 🛠️ Getting Started

### Prerequisites
*   Node.js (>= 18.0.0)
*   npm or yarn

### Installation
1.  Clone the repository.
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Launch the development server:
    ```bash
    npm run dev
    ```
